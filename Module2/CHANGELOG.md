# Changelog

All notable changes to Module 2 (Orthographic Projection of Solids).

## 2026-08-04
- Fixed: the Side view folded down beside the Top view instead of the Front view, violating standard first-angle convention (Side must share Front's height band via shared horizontal projectors, not Top's). The Profile Plane's fold hinge (`ppHingeGroup`) was a world-space sibling of the VP fold pivot (`vpFoldGroup`), folding `−90°` about local X onto the HP; it's now nested inside `vpFoldGroup` and folds `+90°` about local Y into the VP plane about the VP∩PP line, riding the VP's own fold down with the front view. Updated `positionRefLabels()`, `answerSheetBox()`, `drawCompare()`'s `sheetPP` formula and its X1-Y1 reference line (now the VP∩PP hinge, spanning Front+Side), and `projectionDrawer.js`'s flat side-view connector (now ties to the folded Front point). The Step-6 tutorial caption already read correctly ("beside the front") and needed no change — only the code disagreed with its own copy. See `../DECISIONS.md` ADR-106.
- Changed: Show Method's "Watch the turn" control no longer draws a screen-anchored 3D pictorial inset — read both reference textbooks' worked examples cover-to-cover on this exact transition and found neither ever uses a pictorial for it. It now lifts a faded copy of Set 2's own top view directly onto the sheet and rigidly rotates+translates it (no reshaping) into Set 3's start position, with the turn angle marked at the pivot during the motion, matching how the textbooks actually draw this step ("copy the view, turn it about the point of turning"). Lands pixel-exact (not merely close) because Set 3's pose is provably Set 2's pose yawed about world-Y and the top view drops that axis. Net deletion of code: the quaternion slerp, local-space edge cache, and fake-axonometric projector are gone, replaced by a closed-form 2D transform over lines both Sets already carry. Supersedes ADR-101. See `../DECISIONS.md` ADR-104.
- Fixed: the ghost's rotation could visibly spin the long way round — its angle was a raw difference of two `atan2` calls (range `(-2π,2π)` unwrapped), never reduced to the shortest path. Wrapped into `(-π,π]`, provably safe since the real turn (`turnDeg`, the `rng-anglehp`/`rng-anglevp` slider value) never exceeds 90°. See `../DECISIONS.md` ADR-105.
- Changed: the Set 2 → Set 3 ghost turn now plays automatically as part of the Next click that crosses that boundary (`methodController.js` `goNext`), not on a separate click — `#method-tilt` is renamed `#method-replay-turn`, moved off `.method-bar` into a small circular icon beside the Set 3 chip, and now serves as an explicit replay control rather than the primary trigger. Not wired into Skip (contradicts its click-cost-mitigation purpose) or Back. See `../DECISIONS.md` ADR-105.
