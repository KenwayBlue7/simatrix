# Changelog — Projection of Points

## 2026-07-10 (Compare-split viewport sharpness + left-only rail seam)
- Fixed: the 3D viewport rendered soft/mis-scaled in the 50/50 Compare split — entering the split flips the body from a flex row to a CSS grid, and the old resize ran inside a single `requestAnimationFrame` that fired before the grid reflow was laid out, so it measured the pre-split full width and pinned a stale, oversized canvas into the half pane. A new `remeasureAfterReflow` waits a second frame so the renderer is sized to the true pane; verified in-browser (canvas backing = `floor(cssPx × devicePixelRatio)`, razor-sharp in split). (`main.js`.)
- Fixed: the device-pixel ratio is now re-asserted on every resize (`renderer.setPixelRatio`), not just at boot — so browser zoom, a monitor move, or the split can no longer break the 1:1 backing-store mapping. (`main.js`.)
- Changed: the structural hairline under the split now spans only the LEFT (3D) half — it moved from the rail's full-width `border-top` onto `#sim-viewport`'s own `border-bottom`, so the right half (2D drawing → rail) reads as one seamless workbench surface. (`index.html`.)

## 2026-07-10 (UI polish + Compare 2-step visibility fix)
- Fixed: opening Compare while the sheet was folded split the screen but left the 2D (S2) drawing blank until a second click. Root cause: `enterWorkbench` sets `compareOpen`/`workbenchOpen` then unfolds the sheet, and `driveFold` unconditionally closed the Compare card — tearing down the split it was building and skipping the paint. `driveFold` now closes Compare on a FORWARD fold only, so the S2 sheet paints on the first click. (`main.js`.)
- Fixed: the viewport rendered slightly soft — `setSize(…, false)` left the canvas CSS size to `width/height:100%` (a fractional container box) while the backing store used integer px, a sub-pixel upscale. New `pinCanvasSize` pins the display px to the integer logical size (+ `devicePixelRatio || 1` guard). (`main.js`.)
- Added: the fold swoop now lights the **Front** quick-view chip when it lands square-on the flat answer sheet, and re-clicking that lit chip physically REVERSES the fold back to 3D (resetting the fold button) instead of just gliding the camera off a still-flat sheet. (`main.js`.)
- Changed: the 'P' chip now hugs the point — offset `[0.40,0.58,0.40]` → `[0.30,0.44,0.30]` (still clear of p′). (`src/labelLayer.js`.)
- Changed: in the Compare split the quadrant hint ("Above HP, in front of VP") reflows to sit BESIDE the quadrant picker in the empty right-side rail space instead of stacking beneath it. (`index.html`.)
